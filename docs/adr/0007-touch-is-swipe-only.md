# เปิดใช้ touch แต่รับเฉพาะ swipe ซ้าย/ขวา

> ข้อ "ไม่มี tap" ถูกพลิกใน [ADR-0014](0014-the-screen-may-answer-one-kind-of-question.md)
> — เหตุผลที่เขียนไว้ที่นี่ยังจริงทุกข้อ ยกเว้นข้อที่ว่า page rotation ทำแทนได้

ขอบเขตของ v1 เคยระบุว่า touch อยู่นอกขอบเขต **คำตัดสินนั้นถูกพลิกในรอบ multi-page** — XPT2046 บน
SPI แยกถูกนำมาใช้จริง แต่รับท่าทางเดียวคือการลากตามแนวนอนเกินระยะขั้นต่ำ ไม่มี tap ไม่มีโซนแตะ
ไม่มีการลากแนวตั้ง

เหตุผล: จอนี้เป็น resistive จุดเดียว อ่านค่าเป็น ADC ดิบและมี noise การกำหนดให้ต้อง "ลากเกินระยะ"
ทำให้ทนต่อทั้ง noise และการเผลอโดน ซึ่งสำคัญมากสำหรับของที่วางบนโต๊ะให้มือปัดผ่านทั้งวัน ส่วน tap
ลั่นง่ายและต้องการความแม่นทั้งสองแกน แลกมาด้วยความสามารถที่ page rotation ทำแทนได้อยู่แล้ว

ค่าคงที่สำหรับแปลง ADC เป็นทิศทางมาจากการ **วัดของจริง** ผ่านโปรเจกต์ใน `firmware/probe/` แล้ว
ฝังลง firmware — ไม่มีหน้า calibrate ให้ผู้ใช้กด ด้วยเหตุผลเดียวกับ MADCTL และ colour order:
จอ 2.8 นิ้วไม่มีปุ่ม การ calibrate ที่พังคือของที่กู้คืนไม่ได้

## ผลที่ตามมา

ขาที่ `docs/hardware.md` จดไว้ทำเครื่องหมาย `[v2]` — บอร์ดบางรุ่นย่อยอาจไม่มีชิปนี้บัดกรีอยู่ ดังนั้น
swipe ต้องเป็นส่วนเสริมที่ขาดได้ ระบบหลายหน้าต้องใช้งานได้เต็มรูปแบบด้วย page rotation
อย่างเดียวเสมอ
